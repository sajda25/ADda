# Three-minute demo script

**Prep:** `pnpm seed` already applied. Open `http://localhost:3000`.

1. **Landing (15s)** — Read the headline: “Every place has more than one story.” Click **Explore the Story Map**.
2. **Map (20s)** — Note markers are storybooks (size ≈ memory count). Demo district is labeled illustrative.
3. **Coffee House (30s)** — Open **Coffee House Steps** (College Street, Kolkata). Show Most Read ordering.
4. **Two memories (40s)** — Open “The table where we became friends,” then return and open “We disagree about the sugar” (contradiction).
5. **Echoes (20s)** — In a story, scroll to **Stories that echo this memory** and open a related page.
6. **Time layers (15s)** — Use **Explore by Time** / layer filters.
7. **Mural (25s)** — On desktop, show the mural panel + cause explanation; switch epochs E1/E2.
8. **Publish (25s)** — Contribute a short demo memory; confirm success only after the API responds.
9. **Chain (optional)** — Only if contracts are deployed: show a real tx hash + explorer link. Never fabricate one.
10. **Close** — “Social media tells the stories of people. ADda preserves the stories of places.”
